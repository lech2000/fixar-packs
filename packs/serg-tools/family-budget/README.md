# serg-tools/family-budget — пробная публикация

Это тот же пак, что [`packs/example/family-budget`](../../example/family-budget/README.md),
выпущенный под настоящим издателем площадки, чтобы пройти весь путь целиком:
выпуск на GitHub → подача ссылкой → разбор → каталог → договор в деле.

Описание пака, шаги дела и честный список того, чего площадка сегодня не
умеет, — в README примера. Образец договора, который подписывают супруги, —
[`docs/dogovor-obrazec.md`](../../../docs/dogovor-obrazec.md).

Отличия от примера — только `metadata.namespace` и `metadata.publisher`.
